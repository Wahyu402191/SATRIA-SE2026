================================================================================
CARA PASANG YOUTUBE API KEY - SINGKAT!
================================================================================

LANGKAH 1: Ambil API Key dari Google Cloud Console
---------------------------------------------------
1. Buka: https://console.cloud.google.com
2. Klik "Select a project" -> "NEW PROJECT" -> Beri nama (misal: "SATRIA-SE2026")
3. Tunggu project dibuat (muncul notifikasi)
4. Klik menu ☰ (kiri atas) -> "APIs & Services" -> "Library"
5. Cari: "YouTube Data API v3"
6. Klik hasilnya -> Klik tombol "ENABLE"
7. Klik menu ☰ -> "APIs & Services" -> "Credentials"
8. Klik tombol "+ CREATE CREDENTIALS" -> Pilih "API key"
9. API Key muncul di popup -> Klik "COPY" atau CTRL+C untuk salin

LANGKAH 2: Paste API Key ke File .env
--------------------------------------
1. Buka file: .env (di folder SATRIA-SE2026)
2. Cari baris:
   YOUTUBE_API_KEY=your_api_key_here
   
3. Ganti "your_api_key_here" dengan API Key yang sudah disalin
   Contoh:
   YOUTUBE_API_KEY=AIzaSyDxxxxxxxxxxxxxxxxxxxxxxxxxxx
   
4. SAVE file (Ctrl+S)

LANGKAH 3: Restart Aplikasi
----------------------------
1. Tutup jendela aplikasi yang sedang jalan (atau tekan CTRL+C)
2. Jalankan lagi: Jalankan_SATRIA_SE2026.bat
3. API Key sudah aktif!
