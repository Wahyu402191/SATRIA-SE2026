SATRIA SE2026

Sistem Automatis Terpadu Riset Informasi dan Analisis: Platform analisis sentimen komentar media sosial YouTube untuk mendukung program Sensus Ekonomi Badan Pusat Statistik Kabupaten Bangkalan.

Versi 1.0  |  BPS Kabupaten Bangkalan  |  2026
Metode Analisis Sentimen
1

Naive Bayes

Algoritma klasifikasi probabilistik berbasis TF-IDF dan ekstraksi fitur trigram. Model ini dilatih menggunakan 1.200 sampel leksikon Bahasa Indonesia dengan smoothing Laplace alpha 0,5.

2

Support Vector Machine

Klasifikasi Linear SVM dengan parameter C=1,5 dan bobot kelas seimbang. Sangat efektif untuk memetakan teks komentar berdimensi fitur tinggi secara presisi.

3

LSTM

Long Short-Term Memory dengan context window dan pembobotan sekuensial. Mampu memahami urutan kata dan konteks kalimat komentar secara mendalam.

4

IndoBERT

Model transformer dua arah kontekstual khusus Bahasa Indonesia. Menggunakan mekanisme perhatian (attention mechanism) dan penanganan kalimat negasi secara akurat.
